# 大模型智能体与工具调用

智能体（Agent）指让大语言模型在循环中自主决策、调用工具、观察结果并迭代推进
直至完成任务的系统。与一次性的问答不同，智能体强调「规划—行动—观察」的闭环。

## 工具调用 / Function Calling

工具调用是大模型的一项能力：开发者用 JSON Schema 描述可用工具的签名，模型在需要
时不再直接回答，而是输出一个结构化的工具调用请求（工具名加参数）。宿主程序执行
该工具，把结果以工具消息的形式回填给模型，模型再决定是继续调用工具还是给出最终
答案。这个循环就是智能体的核心。

## Agentic RAG

把智能体模式套用到 RAG 上，就得到 Agentic RAG：模型不再对每个问题都无脑检索一次，
而是自主判断是否需要检索、检索几次、要不要改写查询、要不要调用计算器或别的工具。
相比固定流程的 Naive RAG，Agentic RAG 更灵活，但也更需要控制循环步数，避免
无限调用与成本失控。

## 查询改写

在多轮对话中，用户的后续提问常含指代，例如「它的缺点是什么」。若直接拿这句话去
检索，几乎无法命中。查询改写会结合历史对话，把这句补全为「向量检索的缺点是什么」，
再送去检索，从而显著提升多轮场景下的召回率。

## 评测

评测是 RAG 工程中容易被忽视却关键的一环。检索侧可看命中率（Recall@k）与平均倒数
排名（MRR），生成侧可看答案是否忠于检索到的证据（忠实度）、是否回答了问题。
没有评测，优化就无从谈起，也无法判断一次改动到底是变好还是变坏。
